# Syra Launch (Jupiter-energy)

60s cinematic brand launch film: smash cuts, camera shake, tech-house BGM, dense SFX.

```bash
cd videos/syra-launch
npm run studio
npm run render          # out/syra-launch.mp4
npm run render:nobgm    # SFX only
```

Spec: 1920×1080 @ 30fps · 60s
